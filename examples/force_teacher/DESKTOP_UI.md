# B601 中文操作工作台（Teacher capture）

默认入口为 Qt 四页工作台，使用当前 50 Hz Teacher capture 后端。

```powershell
uv sync --locked --extra rebot --extra dataset --extra force-teacher-ui
.\run_force_pos_teacher.bat
```

日常双击桌面的“Force-VLA 数据采集”快捷方式，或根目录唯一的采集启动脚本 `run_force_pos_teacher.bat`。桌面快捷方式直接指向主线目录里的同一脚本，没有独立参数副本。
窗口启动只加载配置；连接、相机预览和运动分别需要显式操作。

Qt 与原 Tk 入口默认读取项目根目录下唯一的日常参数文件 `b601_capture_parameters.json`；“保存参数”也默认更新这一份，下次打开自动加载。`--settings-file` 仍可显式选择其他参数文件。本机旧版本已移到 `outputs/parameter_history_*`，历史采集目录中的配置快照保留供追溯。

- **遥操与录制**：相机快照、当前力、目标力、曲线及连接、启动、录制、保存。
- **调参**：当前控制参数、实时曲线、夹爪定位和运动操作；“释放并结束采集”会追加释放运动。
- **设备与配置**：参数文件、校准、六轴设置、相机角色、录制配置与续录。
- **诊断与记录**：运行状态、错误、退出证据、只读复核及日志目录。

调参页的“手动操作”卡片提供夹爪定位的目标角度、速度和按钮。输入初值来自参数配置，本次输入不会自动保存到参数文件。只读监测时，完成首页机械与力通道确认、取消录制准备后，可以直接启动单夹爪定位；这一会话不录制示范数据。已有控制会话中也可执行定位，在主从模式下会退出自动跟随。两种路径都沿用原有位置、速度和启动检查。“全臂参数与范围”位于“FORCE_POS 与控制时序”下方，展开后页面会滚动到该区域；六轴表格可左右滚动。

调参页的力、位置和控制增量曲线使用统一尺寸及对齐的时间轴，任一图的横向缩放或拖动都会同步到另外两张；力曲线显示左右力、平均力与目标力，并标明反馈是否停更或无效。位置变化率加速度限制的开关和数值位于力控制参数上方；关闭时数值置灰，不参与限制。手动小步和冻结命令已从界面、进程通信和控制器中移除；夹爪定位所需的位置保持，以及定位后的“恢复 I-P”仍保留。旧参数文件可只读加载，已移除的字段不参与控制；新保存的参数文件使用版本 10。

正常结束一条数据请点击“结束并保存”，该操作不追加运动，保存后遥操继续。

默认每段快速保存并显示视频待完整核验；可在录制配置勾选“保存时完整核验视频”。停止采集并确认资源退出后，首页“完整核验”对当前数据集逐帧解码检查，可取消。核验完成后自动显示结果、逐条明细、失败原因和报告路径；关闭结果窗口后可用“查看结果”再次打开。窗口较高时核验区位于右下角，较小时自动调整位置。整批报告写入数据目录旁的 `<目录名>_verification_reports`，不会修改数据集。重启后可手动查看最近的历史报告，历史结果不能证明当前数据集未变化；追加数据或切换目录后须重新核验。

“诊断与记录”中的数据状态和操作记录列出本段保存的排空、事务提交、非视频检查、视频解码和总耗时；这是运行诊断，不写入稳定 Sensor manifest。
随后可开始下一条，或点击顶部“停止 / 失能 Esc”，等待退出收据后关闭窗口。
每条新录制的“任务结果”默认重置为“未确认”，请按该条实际情况选择；人工结果和文件完整性分别显示。
窗口顶部同时显示会话状态与录制状态，切换到调参、设备或诊断页时仍可查看是否正在录制或保存。
首页的录制时长按主帧数除以 50 Hz 估算，不是独立测量的墙钟时间。
机械确认框在只读连接后可勾选，断开时会清除；完成确认后才可点击启动。方框使用不同样式标明未选、已选和不可修改状态。
首页可直接跳转到录制配置或相机绑定，设备页顶部也有快捷跳转；首页显示当前数据目录和续录选项，尚未提交的更改标为“草稿”。

相机独立预览仅在空闲时打开；预览成功关闭后才能交接正式采集。
当前后台最多发布 5 Hz 预览，界面状态默认 10 Hz、曲线绘制 20 Hz；切换页面停止隐藏画面的解码。
画面下方显示最后一帧的更新时间；超过 2 秒未更新或解码失败时显示提示。相机绑定时须先看到两路新画面；画面停更或解码失败时，确认绑定按钮会暂时禁用。此检查只影响界面中的绑定确认，不改变采集门限，也不能证明画面内容正常。断开后首页不再把旧力值显示为实时反馈。
录制请求、采集和清理错误显示在首页提示与“诊断与记录”中。窗口顶部的“问题详情”可在任何页面打开，查看常见问题的中文说明、完整原始报错和关联的运行日志，并可复制全部内容；未知错误仍保留原文，不自动猜测原因。本窗口保留最近 10 条问题，关闭窗口后这份临时记录不保留；已写入的运行日志可在“诊断与记录”中打开。

支持当前入口参数：`--settings-file`、`--calibration-file`、`--recording-config`、
`--gripper-only`、`--command-feedback-mode sequential|pipelined|cached`、`--command-tx-gap-us`。
日常七轴入口默认 `cached` 异步反馈读取、最小发送间隔 `120 μs`（0.12 ms）。根目录启动脚本、直接运行 Qt、`--legacy-ui` 和直接运行 Tk 均采用这组默认值；显式 `--command-tx-gap-us` 优先，其次为 `MOTORBRIDGE_TX_GAP_US` 环境变量。当前本机采集参数文件保持 50 Hz，入口不改写个人参数；2026-10-31 的 5 段实机录制已通过完整数据核验，覆盖范围及内容问题见 [交付记录](DELIVERY_SCOPE.md)。
同一个串口 Owner 在轴间和控制周期之间读取反馈，`cached` 只在原有时效限制内复用最近有效反馈；不另开串口读取线程、不在运行中切换模式。单夹爪定位仍按支持范围使用 sequential。设备页显示本次启动的模式和发送间隔，运行的 `reviewed.json` 记录实际生效配置。录制编码器默认沿用当前 NVENC，可在录制配置 JSON 中指定 software。
已有数据目录的协议与通信策略固定：从 sequential 改用 cached 时应选择新数据目录，不能混合续录或改写旧目录的策略标记。符合当前协议且通信策略一致的目录可正常续录。
相机绑定和参数文件只在显式保存时写入；加载配置不会继承机械确认。

```powershell
# 离线合成演示，不打开硬件或保存正式数据
.\run_force_pos_teacher.bat --demo
# 构建并关闭，不连接设备
.\run_force_pos_teacher.bat --smoke-test
# 原 Tk 面板
.\run_force_pos_teacher.bat --legacy-ui
# 离线测试
uv run --no-sync pytest tests/force_control/test_desktop_ui.py tests/force_control/test_desktop_session.py -q
```

`--connect` 显式启动只读连接，桌面快捷方式不附带此参数。缺少 Qt 依赖时入口显示安装命令，也可在同一个入口使用 `--legacy-ui`。
界面显示的提交、保存完整性和人工结果分别来自原有后端，不推断硬件 ACK 或物理任务成功。
