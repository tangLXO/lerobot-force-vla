# FORCE_POS 夹爪调参

## 启动与配置

```powershell
uv run --no-sync python examples/force_teacher/b601_tuner.py
uv run --no-sync python examples/force_teacher/b601_tuner.py --smoke-test
```

先加载当前 B601 ID7 校准文件，确认闭合方向、端口、X518 通道映射、增益与限制。保存设置仅保存配置，不会自动启动运动；重新加载校准后必须重新读取只读参考。

连接默认只读。显式启动使用同一校准后端与唯一 owner；界面通过参数消息与回执显示请求值和生效值。停止后等待清理完成再重新连接。

`b601_ip_parameters.template.json` 是待填写的配置模板。根目录的 `b601_ip_parameters.json` 与 `b601_ip_parameters_communication.json` 是本机文件，不纳入版本控制。旧设置可读取迁移，原文件不会自动改写。

参数解析、保存与运行配置构建统一由 `lerobot.force_control.tuning` 提供，界面只负责编辑和提交。新保存格式为 v6：夹爪跟随 / 接近速度上限使用 `gripper_follow_speed_deg_s`，接触平均力阈值使用 `contact_force_threshold_N`，并保存 102 连接参数。v1–v5 JSON 和旧 Teacher YAML 仍可读取；旧 `approach_speed_deg_s` / `approach_force_threshold_N` 分别映射到这两个字段，旧新同名含义字段同时出现会被拒绝，不猜测优先级。旧 kg 目标继续按 9.80665 N/kg 转换；增益、速度、限位及底层协议值均不随迁移改动。旧文件的主臂端口默认为空，加载文件不会自动选择或启动 Teacher。

## Teacher 主从夹爪

1. 停止并断开，在“其他设置”中解锁并填写 102 主臂串口，默认使用 `protocol_v1` 只读传输；主从串口不能相同。主臂默认目标采样率为 50 Hz，与 100 Hz 的夹爪控制调度独立。
2. 加载校准与个人参数，设置目标力、Kp/Ki、接触平均力阈值、夹爪跟随 / 接近速度上限及保护限制。
3. 点击“连接 / 只读监测”，确认从爪失能与新鲜反馈；确认机械设置后点击“Teacher 主从夹爪（使能）”。控制进程先验证新鲜主爪读数，再准备并启动 ID7。
4. 运行中使用“应用实时参数”；请求值与生效值以 owner 回执区分。主臂连接、方向和校准必须停止并断开后修改。

| 状态                | 行为                                                                                       |
| ------------------- | ------------------------------------------------------------------------------------------ |
| `FOLLOW`            | 跟随映射后的主爪目标，两向变化率受同一跟随速度及既有 Safety 限制；平均力达到阈值后接触接管 |
| `FORCE_TRACK`       | 持续跟踪设定目标力；力回落不退出，主爪继续闭合不接管                                       |
| `FOLLOW_WAIT_CLEAR` | 人主动张开后跟随；力低于阈值且出现新的闭合意图后重新允许接触接管                           |

接触参考使用当时从爪实测位置。102 原始角度经过原有方向、解绕与限位映射后，已处于从爪的角度坐标，直接比较即可。退出要求接触之后的新主臂样本确实向张开运动，并越过接触从爪参考，且不要求当前从爪重新闭合。界面显示映射主爪位置和已提交的接触参考。

接触位置和状态转换仅在成功提交命令后确认。传感器、主爪或从爪反馈过期时停止；重复读缓存不会刷新指令时效。停止按钮和 Esc 保持可用，主臂只读线程及 B601 owner 完成清理前禁止重开。

冻结、指定位置或恒速接近等手工操作会退出本次自动跟随；恢复 I-P 按独立力控语义运行，主臂新鲜度检查持续到会话停止。重新进入混合 Teacher 需要停止后再次显式启动。全臂控制与数据集录制不在此入口中。

## 控制与单位

- 目标力及死区为 N；Kp 为 °/N，Ki 为 °/(N·s)。Ki=0 时，恒定的力误差不会产生持续积分闭合。
- I-P 使用本周期真实 dt 和相邻成功提交的力样本；修改目标力不制造比例冲击。
- 恒速接近使用接近速度；达到平均力阈值后切入 I-P。指定位置移动另有定位速度。
- 接触时消除之前下发但尚未到达的闭合目标余量；若速度限制只允许部分消除，后续周期继续对齐。真实上次下发目标始终保留，对齐期间不标记为有效力控训练样本。
- 闭合／张开最大速度是外环目标变化率限制，单位 °/s。电机速度码是底层 FORCE_POS 字段，1 码为 0.01 rad/s；驱动百分比也不是目标夹持力。
- GUI 的控制调度目标为 100 Hz；实际频率与超时情况以日志为准。调度超时跳过旧节拍，不补发积压命令。
- X518 每拍选择最新已到达的因果有效样本，左右求平均用于控制；左右分别进行原始力上限保护。

## 记录与验证边界

运行资料位于 `outputs/force_teacher_tuning/`，包含参数、校准来源、候选目标、安全后目标、实际提交目标与退出证据。

独立调参不连接主臂，不驱动其他关节。校准范围、反馈新鲜度、单侧超力、设备故障与手动停止保护始终有效。软件提交、模式读回和离线测试不代表物理到位或硬件 ACK。
